Solo Atlas Documentation

Every endpoint the API supports, what it expects, and what it returns.

GET / HEAD endpoints

All of these support HEAD, which returns the same headers as GET with no body.

Endpoint Parameters Responses
/api/getAllCountries None 200: every country in the dataset
/api/getCountries region and/or subregion 200: matching countries · 400: no filters given · 404: no matches
/api/getCountriesByCurrency currency (required, code like EUR or name like euro), optional region, subregion 200: matching countries · 400: missing currency · 404: no matches
/api/getDistance from, to (both required, country names) 200: distance in km and miles · 400: missing a country · 404: country not found
/api/getVisited None 200: countries added with addVisited
/api/getRatings None 200: solo-travel ratings, highest first

POST endpoints

Bodies can be sent as JSON or as form url encoded.

Endpoint Body Responses
/api/addVisited name (required), optional capital, region, subregion. Blank fields use the dataset's values. 201: added · 204: already in the list, updated · 400: missing name or bad body · 404: country not found
/api/addRating name and rating 1–5 (required), optional capital, comment 201: added · 204: existing rating replaced · 400: missing fields or rating out of range · 404: country not found

Anything else

Any other URL or method returns 404 with a JSON error message.
